# TProgramada3BDI
Objetivos: Implementar una base de datos física, así como escribir el código en capa lógica y física, para la implementación de 2 sitios web (para administradores y empleados), para el mantenimiento de entidades (CRUD) y la realización de consultas. Escribir en SQL un script que realice una simulación la operación del sistema por varios meses.
